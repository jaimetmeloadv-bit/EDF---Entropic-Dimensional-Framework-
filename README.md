#🚀 Running the Notebook

[notebook](https://nbviewer.jupyter.org/github/jaimetmeloadv-bit/EDF/blob/notebook-pipeline/EDF-notebook.ipynb)

. Prerequisites

```bash
pip install numpy pandas matplotlib scipy
```

. Execution

```bash
jupyter notebook EDF-notebook.ipynb
```

. Or run in headless mode:

```bash
jupyter nbconvert --to notebook --execute EDF-notebook.ipynb --output EDF-notebook_executed.ipynb
```
